# 🐾 Mammalian Sleep Data Analysis

An exploratory data analysis project examining biological traits, environmental threat levels, and sleep patterns across various mammal species using Python.

## 📊 Project Overview
This project investigates the relationships between an animal's physical characteristics (body weight, lifespan) and behavioral factors (total sleep, danger index). Using Python libraries, the dataset was cleaned, statistically summarized, and visualized to uncover key trends in the animal kingdom.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Tools:** VS Code, Git/GitHub

## 📈 Key Insights & Visualizations
1. **Body Weight vs. Sleep :** Demonstrates how heavier mammals generally require significantly less sleep compared to smaller mammals.
2. **Correlation Heatmap :** Maps out statistical relationships across numerical features like gestation time, lifespan, and danger indexes.
3. **Top Sleepers :** Highlights the mammal species that log the highest total daily sleep hours.
